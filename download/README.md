## Sample Documents (Download Files)

This directory is the target for the download (`zip`) files of the `hagenberg-thesis` sample documents, which are created by the build (`make documents` in `dev/`).
The `zip` files are not part of the branch `main`: the current versions are published on the branch
[`build`](https://github.com/Digital-Media/HagenbergThesis/tree/build/download) and linked in the main [README](../README.md).

To use any sample document, download the associated `zip` file and create a LaTeX project inside
the expanded document directory, or open the document directly on Overleaf using the links in the README.
