\section*{Main File (\texttt{main.tex})}

\paragraph{Note:}
This should just be an \emph{example} of how to include source code in the
document's appendix. It is accomplished with the following instruction:
%
\begin{LaTeXCode}[numbers=none]
\lstinputlisting[language={},inputencoding=utf8/latin1]{main.tex}
\end{LaTeXCode}
%
Overlong lines are wrapped automatically. Of course, the \latex source code of
one's thesis is usually \emph{not} interesting enough to be reproduced here!

\lstinputlisting[language={},inputencoding=utf8/latin1]{main.tex}
